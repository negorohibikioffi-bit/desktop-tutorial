## Orb Jacket

`orb-jacket/index.html` をブラウザ（PC版 Chrome / Edge / Safari 推奨）で開くと使えます。

1. 「ジャケ写を選ぶ」で画像を読み込む（ドラッグ＆ドロップ・貼り付けでもOK）
2. 角の丸み・オーブの数や輝き・サイズ（1:1 / 9:16 / 16:9）などを調整
3. 必要なら音楽を追加（動画に音が入り、音に合わせて脈打ちます）
4. 「動画を生成」→ 完成したら「動画を保存」

動きは指定した秒数でぴったり1周するので、ループ再生してもつなぎ目が出ません。
